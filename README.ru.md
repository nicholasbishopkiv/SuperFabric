# Фабрика (SuperFabric)

> 🇬🇧 English version: [README.md](README.md)

**Self-hosted визуальный оркестратор мульти-аккаунтных Claude Code агентов.**

Браузерное приложение-«завод»: бесконечный canvas, в центре — блок проекта (его документация и направление), вокруг — комнаты-отделы (backend, frontend, devops…). В каждой комнате живут агенты — отдельные сессии Claude Code, привязанные к разным подписочным аккаунтам и работающие в изолированных окружениях. Отделы общаются через центральную MCP-шину фабрики, главный оркестратор следит за ходом работ, а UI показывает в реальном времени: кто работает, кто ждёт, кто упёрся в лимиты и когда они сбросятся.

## Зачем

- **Согласованность команд-агентов**: один проект, много зон ответственности, общее понимание «куда движемся».
- **Мульти-аккаунт**: 2–3 подписки Claude (Pro/Max) работают параллельно, лимиты видны по каждой, работа не останавливается.
- **Визуализация**: весь ход разработки — открытые таски, блокеры, переписка отделов — виден на одном экране.
